# 策略运行时真实因子回调适配器接线说明（2026-05-31）

## 1. 本次新增能力

已在策略运行时新增 `CallbackRuntimeFactorServiceAdapter`，用于把外部真实因子服务通过回调注入到 `IRuntimeFactorService`。

相关代码：
- src/domain/strategy/include/IStrategyService.h
- src/domain/strategy/include/RuntimeStrategyFactory.h
- src/domain/strategy/src/StrategyRealFactorAdapter.cpp
- src/domain/strategy/src/RuntimeStrategyFactory.cpp
- src/domain/strategy/src/StrategyEngineFacade.cpp（已支持 withFactorService(...) / withFactorCallbacks(...) 注入）

## 2. 设计目的

- 不改订单服务。
- 不把 bridge/QVariantMap/QString 引入运行时主链。
- 先打通“可注入真实因子实现”的稳定边界，并由组合根显式注入真实因子服务。

## 3. 使用方式（示意）

```cpp
using namespace domain::strategy;

CallbackRuntimeFactorServiceAdapter::Callbacks cbs;
cbs.updateIncremental = [&](const MarketDataPoint& point) {
    // 调你的真实因子增量更新入口
    return StrategyServiceFlowResult(StrategyServiceFlowCode::Ok);
};
cbs.updateBatch = [&](const std::vector<MarketDataPoint>& batch) {
    // 调你的真实因子批量更新入口
    return StrategyServiceFlowResult(StrategyServiceFlowCode::Ok);
};
cbs.copySnapshots = [&](std::vector<RuntimeFactorSnapshot>& outputSnapshots) {
    // 输出当前真实因子结果快照
    outputSnapshots.clear();
};

auto engine = StrategyEngine::builder()
    .withFactorCallbacks(std::move(cbs))
    .build();
```

## 4. 失败语义

- 若回调未完整注入，适配器直接返回 `InvalidState` 或空快照，不回退 pseudo。
- 真实因子实现出错时，应在回调内部显式返回对应 `StrategyServiceFlowCode`。

## 5. 下一步建议

1. 先把 domain/factor 的增量/批量更新入口映射到 `updateIncremental/updateBatch` 回调。
2. 在 `copySnapshots(...)` 中输出共享 `FactorSnapshot` 合同对应的数据。
3. 增加一组接线回归测试（真实回调注入后策略主链可跑通）。

## 6. 运行时策略桥接（已落地）

- 已新增多因子运行时策略工厂 `createMultiFactorSelectionRuntimeStrategy(...)`，用于把
    `domain::strategies::MultiFactorSelectionStrategy` 包装为 `IRuntimeStrategy`。
- 已新增多因子运行时引擎单入口工厂 `createMultiFactorRuntimeEngine(...)`，用于集中完成：
    1. 因子回调注入
    2. 运行时策略创建
    3. 策略注册到 `StrategyEngine`
- 工厂输出的运行时策略直接消费共享 `FactorSnapshot` 快照，并生成 `StrategySignal`。
- 当前支持：
    1. Long/Short 方向（遵循 `allowShort`）
    2. 权重方案：`EQUAL`、`SIGNAL_STRENGTH`
    3. 权重约束：`minWeightPerStock`、`maxWeightPerStock`、`RuntimeStrategyContext.maxTargetWeight`
- 运行时回归：`tests/test_strategy_runtime_multifactor.cpp` 已验证：
    1. “策略定义 -> 运行时信号”链路
    2. “withFactorCallbacks -> StrategyEngine::stepBatch -> OrderRequest”链路
