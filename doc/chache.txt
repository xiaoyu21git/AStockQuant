数据库字段 / 清洗字段 / 缓存字段一致性分析

| 字段 | 数据库 | 清洗合同 | 默认财务清洗 | 缓存文档 | 实际缓存实现 | 结论 |
|---|---|---|---|---|---|---|
| disclosure_date | 不直接落库，实际使用 effective_disclosure_date | 有 | 无 | 无 | 有，作为财务日期对齐语义字段保留 | 语义一致，物理列名不一致 |
| gross_margin | 有 | 有 | 有 | 无 | 有 | 一致 |
| operating_margin | 有 | 有 | 有 | 无 | 有 | 一致 |
| dividend_yield | 有 | 有 | 有 | 无 | 有 | 一致 |
| payout_ratio | 有 | 有 | 有 | 无 | 有 | 一致 |
| dividend_stability | 有 | 有 | 有 | 无 | 有 | 一致 |

结论：数据库和清洗合同已经对齐；从代码可见，清洗后只会移除 legacy 字段，清洗类数据集的可用字段由 contractAvailableFieldsForSelectedDataTypes 动态计算。当前不一致的是这份文档还没同步到新字段。
