# 策略类型去字符串化整改清单

## 目标

- C++ 内部语义只允许枚举、索引、结构体，不允许用字符串承载策略类型、子类型、行为类型、运行属性类型。
- QML 页面状态只允许整型合同，不允许再保留 selectedStrategyType、subType、assetType、timeFrame、riskLevel 这类字符串状态作为真实数据源。
- 字符串只允许保留在受控边界：数据库落库文本字段、元数据 JSON 键、国际化展示键、纯展示文案。
- 禁止字符串参与分发、回退、推断、兼容映射；缺失整型合同直接失败。

## 本轮审计结果

初始审计与后续补充追踪针对策略创建链、服务层、仓储层、回测链主路径，共识别出 15 组残留热点。当前已完成其中 8 组，剩余 7 组，分成三类：

### P0 立即整改

1. 已完成：StrategyCreationPagePro.qml 原 assetType、timeFrame、riskLevel 字符串页面状态已删除。
2. 已完成：StrategyCreationPagePro.qml 创建提交不再主动写入 strategy_type 字符串。
3. 已完成：StrategyCreationPagePro.qml 的 mapStrategyTypeToBackend 字符串映射死代码已删除。
4. 已完成：StrategyService.h / StrategyService.cpp 的 getAvailableStrategyTypes / getStrategyTypeDescriptions 字符串类型 API 已删除。
5. 已完成：StrategyService.cpp 的 STRATEGY_TYPE_DESCRIPTIONS / STRATEGY_TYPE_MAPPING 静态字符串映射已删除。
6. 已完成：StrategyCreationUtils.js 的 backendStrategyTypeFromBehaviorKind 已删除。

### P1 受控边界，允许保留但必须限域

7. StrategyRepository.cpp 的 strategy_type、status、language 是当前数据库 schema 文本字段，属于持久化边界，不允许向业务层扩散。
8. StrategyService.cpp 的 applyCanonicalStrategyIdentity 会补 strategy_type，这里只允许作为仓储边界字段，不允许作为前端输入合同。
9. 2026-05-26：strategy_type 持久化边界必须支持 `CUSTOM`，否则 Custom 强类型策略会在数据库 UPDATE/INSERT 阶段直接失败；该支持只能停留在 schema 边界，不允许反向变成前端字符串合同。
10. StrategyCreationUtils.js 内部仍有 typeId 字符串，仅用于 i18n key、图标、展示说明，允许保留在展示层，不允许回流为业务合同。
11. StrategyMetaLoader.js 用 strategyType 字符串读取元数据 JSON，这是外部元数据键，不允许参与运行期类型判定。

### P2 下一批整改

11. 已完成：StrategyBacktestPage.qml 不再写入 selectedStrategyType / selectedStrategySubtype 字符串上下文。
12. 已完成：FactorBacktestPage.qml 不再写入 strategy_type / sub_type，也不再向 strategyScopeContext 写 selectedStrategyType / selectedStrategySubtype。
13. 未完成：StrategyDataAdapter.js / StrategyLibraryPage.qml 仍把 strategyType / subType 当展示模型主字段。
14. 未完成：RiskConfigurationPage.qml 仍直接比较 strategy_type 文本判断 PORTFOLIO。
15. 未完成：StrategyBacktestController.cpp 历史上会把 selectedStrategyType / selectedStrategySubtype 转写到 strategyOptions；本轮主链已切断该行为，但展示/结果适配层仍有旧字段残留待读取侧收口。

## 当前执行口径

- 前端创建链输入合同：只认 strategyTypeIndex、strategyBehaviorKind、assetTypeIndex、timeFrameIndex、riskLevelIndex、statusIndex。
- 服务层输入合同：只认整型合同；旧字符串字段只允许被显式拒绝，不允许驱动逻辑。
- 仓储层参数 JSON：只保存 assetTypeIndex、timeFrameIndex、riskLevelIndex，不再保存 asset_type、time_frame、risk_level。
- 展示层字符串：只允许由索引派生，不允许反向推断业务类型。

## 本轮落地范围

4. 删除仅用于上述路径的 backendStrategyTypeFromBehaviorKind。
