# 策略类型去字符串化整改清单

## 目标

- C++ 内部语义只允许枚举、索引、结构体，不允许用字符串承载策略类型、子类型、行为类型、运行属性类型。
- QML 页面状态只允许整型合同，不允许再保留 selectedStrategyType、subType、assetType、timeFrame、riskLevel 这类字符串状态作为真实数据源。
- 字符串只允许保留在受控边界：数据库落库文本字段、元数据 JSON 键、国际化展示键、纯展示文案。
- 禁止字符串参与分发、回退、推断、兼容映射；缺失整型合同直接失败。

## 本轮审计结果

初始审计与后续补充追踪针对策略创建链、服务层、仓储层、回测链主路径，共识别出 15 组残留热点。当前已完成其中 8 组，剩余 7 组，分成三类：

3. 已完成：StrategyCreationPagePro.qml 的 mapStrategyTypeToBackend 字符串映射死代码已删除。

### P1 受控边界，允许保留但必须限域

9. 2026-05-26：strategy_type 持久化边界必须支持 `CUSTOM`，否则 Custom 强类型策略会在数据库 UPDATE/INSERT 阶段直接失败；该支持只能停留在 schema 边界，不允许反向变成前端字符串合同。
10. StrategyCreationUtils.js 内部仍有 typeId 字符串，仅用于 i18n key、图标、展示说明，允许保留在展示层，不允许回流为业务合同。
11. StrategyMetaLoader.js 用 strategyType 字符串读取元数据 JSON，这是外部元数据键，不允许参与运行期类型判定。

## 当前执行口径

- 前端创建链输入合同：只认 strategyTypeIndex、strategyBehaviorKind、assetTypeIndex、timeFrameIndex、riskLevelIndex、statusIndex。
- 服务层输入合同：只认整型合同；旧字符串字段只允许被显式拒绝，不允许驱动逻辑。
- 仓储层参数 JSON：只保存 assetTypeIndex、timeFrameIndex、riskLevelIndex，不再保存 asset_type、time_frame、risk_level。
- 展示层字符串：只允许由索引派生，不允许反向推断业务类型。

## 2026-08-13 增补：C++ 枚举为唯一事实源，DB 存枚举名字符串

> 背景：编辑"机器学习+ai因子20天持仓+熊市不开新仓"策略时 UI 显示"多因子"而非"机器学习"。
> 根因：metadata_json 存纯数字 strategyTypeIndex=4/behaviorKind=4，且 JS 层双编号家族一数多义
> （StrategyCreationUtils.js 有"有因子配置就强制 MultiFactor"的语义错误逻辑）。

### 新契约（与原清单的差异点）

1. **枚举名字符串只出现在受控边界**：数据库落库文本字段 `metadata_json.strategyType` 与
   `parameters.rule_profile.strategyProfile.strategyType`、元数据 JSON 键、展示层——与原清单 P1 第 7/10 条
   允许保留的边界一致，但解析严格无回退（缺失/非法枚举名 → 直接失败，不再有数字回退链）。
2. **C++ 枚举是唯一事实源**：`domain::strategies::StrategyTypeRegistry`（header-only，Qt-free）提供
   typeId/fromTypeId/behaviorKindOf/storedTypeOf/backtestBehaviorKindOf；QML 经 `Bridge.StrategyTypes`
   枚举契约（StrategyTypeContract，qmlRegisterUncreatableType）引用，不建任何 JS 类型体系。
3. **behaviorKind 不再存储**：一律由 strategyType 推导（桥接层与仓储层同用 behaviorKindOf），
   payload 携带 strategyBehaviorKind 即拒绝。
4. **已删除**：JS StrategyCreationUtils.js / StrategyStructureAdapter.js 整体删除（双编号家族、
   normalize 家族、强制 MultiFactor 语义错误块全部不留）；ResolvedStrategyBehaviorVariant.h 与
   resolveStrategyStoredType/resolveStrategyBehavior 自由函数删除；桥接层 toBk/fromBk/findMeta/
   normalizeStrategyTypeIndex 等数字兼容路径全部删除。
