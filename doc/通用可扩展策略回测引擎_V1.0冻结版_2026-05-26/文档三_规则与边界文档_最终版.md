# 文档三：规则与边界文档（最终版）

**版本**：V1.0（已冻结）  
**日期**：2026-05-26  

> 说明：本文是冻结设计稿，不代表当前仓库实现。当前代码里旧 `StrategyBacktestService` 已删除，旧共享 `BacktestEngine` 已收紧替换为 factor/group 专用 `FactorBacktestEngine`；文中边界与组件命名应按目标设计概念理解。

本文档严格界定引擎内外职责、规则执行逻辑及不可逾越的硬约束。

## 1. 引擎内部规则逻辑（必须实现）

1. **分层候选池约束**  
   每层因子计算、标准化、合成必须在其声明的输入候选池内进行。下层不得越界，引擎自动丢弃池外信号。

2. **因子域隔离校验**  
   - 合成前验证所有参与因子值的 `universeId` 完全相同。  
   - 验证所有因子值对应的数据时间戳符合“信息截止时间一致”原则（日频因子使用 T-1 收盘数据，分钟因子使用上一完整分钟数据）。  
   - 校验失败立即终止回测，无降级模式。

3. **外部规则检查调用**  
   - 对每一笔候选入场或持仓，强制调用 `IRuleChecker::checkRules(ctx, symbol, decisionType)`。  
   - `blocked == true`：取消该标的本期入场。  
   - `forceExit == true`：立即以市价平仓该标的。  
   - 引擎不解析、不质疑规则结果。

4. **持仓与资金管理规则**  
   - 买入资金不超过当前可用现金。  
   - 单只股票持仓比例不超过 `RiskSpec` 中的单票上限。  
   - 总持仓比例不超过总仓位上限。  
   - 下单数量按交易所整手（100股）向下取整。  
   - 每日结算后更新权益曲线。

5. **执行模拟规则**  
   - 仅通过 `IExecutionSimulator::execute(order, currentData)` 获得成交结果，不假设一定成交。  
   - 成交后立即同步更新持仓、现金、权益。

6. **结果摘要规则执行统计**  
   收集每次 `IRuleChecker` 调用的结果，汇总阻断次数、强制退出次数及原因分布，写入 `RuleTemplateSummary`。

## 2. 外部模块职责（引擎绝不涉足）

| 模块 | 职责 | 对应接口 |
| :--- | :--- | :--- |
| 数据缓存 | 数据清洗、复权、分红、停牌处理、财务数据 PIT、提供预热数据 | `IMarketDataCache` |
| 规则引擎 | 规则 DSL 解析、模板管理、规则条件判断、组合与优先级 | `IRuleChecker` |
| 执行模拟 | 订单簿重建、撮合逻辑、滑点模型、冲击成本、挂单管理 | `IExecutionSimulator` |
| 组合优化 | 权重分配、行业中性、优化约束处理 | `IPortfolioOptimizer` |
| 绩效分析 | 归因计算、报表、图表数据生成 | `IAnalyzer` |
| 参数优化 | 网格搜索、遗传算法、过拟合检验 | 应用层（多次调用 `execute()`） |
| 实盘桥接 | 信号转换、订单下发、回测-实盘差异分析 | 实盘适配层 |

## 3. 硬边界清单（不可逾越）

- 引擎不进行任何 I/O，所有数据在启动前通过 `IMarketDataCache` 加载完毕。
- 引擎不解析规则 DSL，不持有规则定义，仅依赖 `IRuleChecker` 接口返回的结果。
- 引擎内部不修改传入的数据视图，所有数据访问为只读。
- 热路径（bar 循环、信号计算）严禁动态内存分配。
- 因子合成前必须校验候选池一致性和时间戳对齐，失败直接终止回测，无降级模式。
- 规则返回的 `blocked` 或 `forceExit` 决定为最终，引擎无权忽略或调整。
- 引擎已知的简化假设（如“使用完整日线”、“按收盘价成交”）必须写入 `diagnostics.assumptions`。
- 引擎不保留策略定义的动态链接，基于快照运行，回测期间策略修改不影响运行中实例。

## 4. 默认行为与可替换点

| 组件 | 默认实现 | 可替换 |
| :--- | :--- | :---: |
| 数据缓存 | 无（必须外部提供） | 是 |
| 规则检查 | 可提供 `NoOpRuleChecker`（永不阻断） | 是 |
| 执行模拟 | `FastExecutionSimulator`（按 bar VWAP/固定滑点成交） | 是 |
| 组合优化 | `EqualWeightOptimizer`（等权分配） | 是 |
| 分析器 | 无 | 是（可选） |
