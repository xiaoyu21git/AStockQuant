本文档以时序图形式描述各组件在一次回测运行中的交互顺序及多频率协作过程。

## 1. 回测引擎核心时序

参与者：ApplicationService, BacktestEngine, MarketDataCache, RuleChecker, ExecutionSimulator, PortfolioOptimizer

```text
ApplicationService -> BacktestEngine: execute(request)
activate BacktestEngine
BacktestEngine -> BacktestEngine: validate(request)
BacktestEngine -> MarketDataCache: getSlice(预热数据)
MarketDataCache --> BacktestEngine: 列式数据指针

loop 每个交易日
    alt 调仓日
        BacktestEngine -> BacktestEngine: 执行L1 overlay
        BacktestEngine -> RuleChecker: checkRules(L1候选, ENTRY)
        RuleChecker --> BacktestEngine: RuleCheckResult
    end

    BacktestEngine -> BacktestEngine: 执行L2 overlay
    BacktestEngine -> RuleChecker: checkRules(L2候选, ENTRY)
    RuleChecker --> BacktestEngine: RuleCheckResult

    alt 启用日内
        loop 每分钟
            BacktestEngine -> BacktestEngine: 执行L3 overlay
            BacktestEngine -> RuleChecker: checkRules(L3触发, ENTRY)
            RuleChecker --> BacktestEngine: RuleCheckResult
            BacktestEngine -> PortfolioOptimizer: computeWeights(候选)
            PortfolioOptimizer --> BacktestEngine: 目标权重
            BacktestEngine -> ExecutionSimulator: execute(订单)
            ExecutionSimulator --> BacktestEngine: 成交记录
            BacktestEngine -> BacktestEngine: 更新持仓/现金
        end
    else 无日内
        BacktestEngine -> PortfolioOptimizer: computeWeights(L2清单)
        PortfolioOptimizer --> BacktestEngine: 目标权重
        BacktestEngine -> ExecutionSimulator: execute(批量订单)
        ExecutionSimulator --> BacktestEngine: 成交记录
        BacktestEngine -> BacktestEngine: 更新持仓/现金
    end

    BacktestEngine -> BacktestEngine: 记录权益/交易/基准对比
    BacktestEngine -> ApplicationService: 可选进度回调
end

BacktestEngine -> BacktestEngine: 生成BacktestResultDto
opt 注入IAnalyzer
    BacktestEngine -> IAnalyzer: analyze(result)
    IAnalyzer --> BacktestEngine: 补充诊断/归因
end
BacktestEngine --> ApplicationService: BacktestResultDto
deactivate BacktestEngine
```

## 2. 多频率分层策略一日时序（月度调仓日示例）

日期：2025-01-15（调仓日）

```text
开盘前: MarketDataCache 确保分钟数据预热就绪
09:30    市场开盘，分钟bar开始生成
09:31    引擎分钟循环: 执行L3层检查，无信号
...      持续监控
14:55    L3触发买入信号（某股票在L2清单内）
         -> RuleChecker.checkRules 通过
         -> ExecutionSimulator.execute 成交
         -> 持仓更新
14:56-15:00 继续L3监控
15:00    收盘，日频bar生成
         -> 执行L1月度再平衡（如需要）
         -> 执行L2精选（基于今日收盘价因子，输出明日清单）
         -> 记录权益、交易、基准对比
         -> 结算持仓市值
15:05    当日处理完毕，输出诊断
```
