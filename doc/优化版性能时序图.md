# 优化版性能时序图

> 融合全部性能优化策略后的系统交互流程，展示**数据层、计算层和资源管控层**的具体优化动作。

## 核心优化策略一览

| 层级 | 优化手段 |
|------|----------|
| **数据服务** | 列式存储 + 内存映射，按批次分块返回，避免全量加载 |
| **因子引擎** | 并行 + 向量化计算，缓存公共因子供后续复用 |
| **策略引擎** | 向量化生成信号，无逐行循环 |
| **回测引擎** | 矩阵运算一次性计算损益，不再逐日迭代 |
| **任务调度/资源管控** | 设置低进程优先级、CPU亲和性，动态监控资源使用，必要时触发降速或分批 |
| **数据类型** | 传输时统一使用 `float32` 等轻量结构 |

## 三大入口流程说明

### 1. 因子回测入口

- 通过调度器提交任务，控制内存上限并分批次处理（每批 500 只股票）
- 数据服务以列式存储 + 内存映射读取，返回 `float32` 行情矩阵
- 因子引擎先查缓存，命中直接返回；未命中则通过并行线程池 + SIMD 向量化计算
- 汇总因子分析指标（IC/IR/分层）后生成报告

### 2. 策略回测入口

- 同样分批处理，通过调度器控制资源
- 因子引擎复用缓存中的公共因子，仅计算新增部分
- 策略引擎通过向量化阈值/排序生成信号，无逐行循环
- 回测引擎使用矩阵运算一次性计算每日损益，滑点和手续费也向量化处理
- 最终生成包含夏普比率、最大回撤等指标的详细报表

### 3. 实盘交易入口

- 绑定固定 CPU 核心，避免与其他任务互相干扰
- 接收实时增量数据流
- 因子引擎以单线程低延迟模式进行增量更新
- 策略引擎生成订单列表，通过交易网关发送实际委托
- 实时记录持仓、损益、风险敞口等风控指标

## 资源管控机制

| 管控阶段 | 具体措施 |
|----------|----------|
| **启动时** | 设置进程低优先级，绑定 CPU 亲和性（预留 1-2 核） |
| **运行时** | 持续监控 CPU/内存/温度指标 |
| **超阈值** | 自动降速或挂起任务，避免系统过载 |
