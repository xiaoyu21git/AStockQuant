# 因子回测结果显示修复总结

## 问题描述
在因子回测功能中，UI界面无法正确显示回测结果。具体问题是：
1. `FactorBacktestController.cpp`中的`convertGroupsToVariantList`函数尝试访问`engine::BacktestResult`类中不存在的成员
2. 错误信息：类 "engine::BacktestResult" 没有成员 "totalReturn"、"volatility"、"sharpeRatio"、"maxDrawdown"

## 根本原因分析
通过分析代码发现：
1. `engine::BacktestResult`类使用嵌套结构体来组织数据，而不是直接成员变量
2. 正确的访问方式是通过访问器方法获取嵌套结构体，然后访问结构体成员
3. 具体结构：
   - `performance().total_return` 而不是 `totalReturn`
   - `risk_metrics().volatility` 而不是 `volatility`
   - `risk_metrics().sharpe_ratio` 而不是 `sharpeRatio`
   - `risk_metrics().max_drawdown` 而不是 `maxDrawdown`

## 修复方案
修改`src/ui/bridge/src/FactorBacktestController.cpp`中的`convertGroupsToVariantList`函数：

### 修复前代码：
```cpp
if (i < result.groupBacktestResults.size()) {
    const auto& backtestResult = result.groupBacktestResults[i];
    groupReturn = backtestResult.totalReturn;
    volatility = backtestResult.volatility;
    sharpeRatio = backtestResult.sharpeRatio;
    maxDrawdown = backtestResult.maxDrawdown;
}
```

### 修复后代码：
```cpp
if (i < result.groupBacktestResults.size()) {
    const auto& backtestResult = result.groupBacktestResults[i];
    // 使用正确的访问器方法
    groupReturn = backtestResult.performance().total_return;
    volatility = backtestResult.risk_metrics().volatility;
    sharpeRatio = backtestResult.risk_metrics().sharpe_ratio;
    maxDrawdown = backtestResult.risk_metrics().max_drawdown;
}
```
