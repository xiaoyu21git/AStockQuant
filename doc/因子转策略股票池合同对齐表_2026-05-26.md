# 因子转策略股票池合同对齐表

更新时间：2026-05-26

## 1. 目标

本文用于把“当前实现”和“目标实现”在因子层、策略层、股票池字段、入口读取方式上的差异直接列成对齐表，作为本轮删除歧义代码和收紧合同的执行清单。

## 2. 现状与目标对齐表

| 对齐维度 | 当前实现 | 目标实现 | 本轮处理 |
| :--- | :--- | :--- | :--- |
| 因子定义与股票池关系 | 因子定义本身未永久绑定股票池，但单次回测结果也没有正式股票池字段 | 因子定义保持可复用；单次回测结果必须正式携带股票池快照 | 保持因子定义不绑池，给结果合同补 `config.backtestSymbolPool` |
| 因子回测结果股票池字段 | 结果 `config` 没有正式股票池字段，页面靠旧字段名或缓存集临时反推 | 结果只输出 `config.backtestSymbolPool` | 新增正式字段，禁止旧字段结果回退 |
| 因子页比较股票池 | 读取 `previousBacktestReport.config.symbol_pool / symbolPool / selectedSymbols`，当前值直接取缓存集股票列表 | 比较只认回测结果里的 `config.backtestSymbolPool` | 删除旧字段读取，删除“结果缺失时冒充当前结果池”的做法 |
| 因子页转策略入口 | 当前直接把缓存集股票列表塞进策略请求 | 只允许把当前因子回测结果的 `backtestSymbolPool` 塞进策略请求 | 改为结果驱动；没有正式股票池时禁止转策略 |
| 策略页接收回测池 | 现有读取口径混有旧字段和策略池字段 | 只认 `backtestSymbolPool` 作为回测池输入 | 本轮把因子转策略链上的读取口径收紧到单字段 |
| 策略创建/保存回测池 | 创建页只展示导入池信息，保存时可能丢掉导入因子池，更新后无法恢复真实回测池 | 保存时必须把 `factorImportContext.backtestSymbolPool` 物化为 `parameters.backtest_symbol_pool`，并把 `factorImportContext` 一起写进 `parameters`，供后续编辑和策略回测恢复 | 本轮在 StrategyService 的策略性能回写链和持久化链统一提升导入因子池，不再依赖页面额外补顶层字段 |
| 策略回测职责 | 容易和因子结果职责混淆 | 在因子股票池基础上叠加规则、仓位、调仓、风控、执行 | 文档固定分层；代码入口按该边界收口 |

## 3. 因子层与策略层分工对齐表

| 层级 | 拥有内容 | 禁止越界内容 | 输出结果 |
| :--- | :--- | :--- | :--- |
| 因子层 | 候选股票范围、因子值、排序、分组、IC、研究指标 | 不允许把最终成交结果伪装成因子股票池；不允许靠旧字段名输出第二套股票池 | `config.backtestSymbolPool` + `metrics.*` |
| 策略层 | 在因子股票池基础上应用规则、仓位、调仓、风控、执行 | 不允许偷偷改成别的股票池来源；不允许把策略最终持仓反写成因子股票池 | `strategyScopeContextSnapshot.backtestSymbolPool` + 交易/持仓/绩效结果 |

## 4. 需要删除的歧义路径

| 文件/位置 | 当前歧义 | 删除后口径 |
| :--- | :--- | :--- |
| `FactorBacktestPage.qml` 股票池比较逻辑 | 读取 `symbol_pool`、`symbolPool`、`selectedSymbols` | 只读 `config.backtestSymbolPool` |
| `FactorBacktestPage.qml` 转策略请求 | 直接使用 `currentCacheDatasetStockCodes()` | 只使用当前展示结果的 `config.backtestSymbolPool` |
| `FactorBacktestPage.qml` 转策略可用性判断 | 只检查缓存集是否有股票 | 必须检查当前因子结果是否存在正式股票池 |
| `FactorWorkbench.qml` 回测报告股票池解析 | 通过通用适配器混读多个字段 | 因子报告路径只认 `config.backtestSymbolPool` |

## 5. 本轮硬约束

- 不新增同语义字符串别名字段。
- 不保留因子结果股票池的旧字段回退读取。
- 不允许页面在结果缺失时用缓存集股票列表冒充“本次因子回测股票池”。
- 不允许因子转策略入口在缺少正式股票池时继续启动。
- 不允许策略保存链只保留导入股票池数量而丢掉真实代码列表；导入池必须进入正式持久化字段。
