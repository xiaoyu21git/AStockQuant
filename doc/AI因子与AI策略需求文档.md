## 二、AI 策略重新设计

### 2.1 为什么原 PPO 方案不行

原方案 (`v0.14.0`): RL 单模型端到端决策 — 输入因子值+持仓, 输出 Top-K 选股。

问题:
1. A 股不是选股就能赚钱的市场 — **择时权重远大于选股**
2. PPO 高维动作空间 (5000→50) 训练极不稳定
3. RL 黑盒, 出问题无法排查
4. 无法融入已知有效的规则 (均线择时、行业中性、风控熔断)

### 2.2 新方案: 分层决策

```
Layer 1: 选股层     AI 因子 + 传统因子 → 全市场排序 → Top-N 候选池
Layer 2: 过滤层     行业中性 + 涨跌停/停牌/ST + 流动性阈值
Layer 3: 择时层     大盘环境判断 → 决定仓位比例 (0~100%)
Layer 4: 配仓层     候选池内按因子值加权, 单票上限 5%
Layer 5: 风控层     回撤熔断 + 单日亏损上限 + 黑名单
```

每层独立可替换。AI 只在选股层发挥作用, 其他层用规则。(后续择时层也可以接 AI 升级)

### 2.3 选股层详解

**输入**: v9 AI 因子值 + 至少 2 个传统因子 (价值/质量/低波任选)

**处理**:
1. 每个因子独立排序 → 百分位得分
2. 多因子得分 = Σ weight_i × score_i (AI 因子权重默认 0.6)
3. 按综合得分取 Top-N (N 默认 200, 可通过策略参数配置)

**为什么不用纯 AI 因子?**
- 单因子风险: 风格反转时 AI 因子可能系统性失效
- 价值因子在熊市防御力强, AI 因子在震荡+趋势市强, 互补
- 多因子组合的 IC 更稳定 (降低因子特异性波动)

### 2.4 择时层详解

**输入**: 大盘指数 (000300.SH / 000905.SH) 的均线结构 + 市场宽度

**规则** (v1, 后续可升级为 AI 择时):
```
IF 上证指数收盘 > MA60 AND MA20 > MA60 AND 上涨家数 > 下跌家数:
    仓位 = 100%  (进攻)
ELIF 上证指数收盘 > MA60 AND 上涨家数 < 下跌家数 × 0.7:
    仓位 = 50%   (谨慎)
ELIF 上证指数收盘 < MA60:
    仓位 = 20%   (防御，仅保留底仓)
ELIF 上证指数收盘 < MA20 AND 连续3日创新低:
    仓位 = 0%    (空仓)
```

**回测验证**: 用 2020-2026 数据回测择时规则, 确认能避开 2022 年和 2024 年中的主跌段。

### 2.5 配仓层

**逻辑**: 候选池内按综合因子得分降序分配权重, 得分越高仓位越重。

```
weight_i = score_i / Σ scores  (归一化)
capped_weight_i = min(weight_i, 5%)  (单票上限)
剩余权重重新分配给未达上限的标的, 直到所有资金分配完毕
```

### 2.6 风控层

| 规则 | 触发条件 | 动作 |
|------|----------|------|
| 回撤熔断 | 当日净值 < 前高 × 0.85 | 清仓, 5天内禁止开仓 |
| 单日亏损 | 当日浮亏 > 3% | 减仓至 50% |
| 黑名单 | 个股连续 3 日跌停 | 移出候选池 20 日 |
| 流动性 | 日成交额 < 2000万 | 不纳入候选池 |

## 三、信号流水线

```
盘后 (15:30)
  │
  ├─ 1. AI因子计算 (C++ FeatureTensorBuilder + ONNX)
  │      └─ 输出: 5000+ 股票的因子值
  │
  ├─ 2. 传统因子计算 (已有, C++)
  │      └─ 输出: 价值/质量/低波等因子值
  │
  ├─ 3. 选股层: 多因子综合排名
  │      └─ 输出: Top-200 候选池
  │
  ├─ 4. 过滤层: 行业中性 + 涨跌停/ST/流动性
  │      └─ 输出: 过滤后的候选池 (~150只)
  │
  ├─ 5. 择时层: 大盘状态判断
  │      └─ 输出: 目标仓位比例 (0/20/50/100%)
  │
  ├─ 6. 配仓层: 因子值加权分配
  │      └─ 输出: 目标持仓清单 [{symbol, target_weight}]
  │
  └─ 7. 风控层: 熔断/止损检查
         └─ 输出: 最终调仓指令 → 交易执行
```

## 四、AI 在哪里发挥作用

| 层 | 当前方案 | AI 升级路线 |
|------|----------|------------|
| 选股 | AI 因子 (v9) + 传统因子 | v9→v10 Transformer / 多尺度 |
| 过滤 | 规则 | — (规则足够) |
| **择时** | **规则 (均线+宽度)** | **ML 分类器: 预测未来N日大盘方向** |
| 配仓 | 因子加权 | RL 学习最优权重分配 |
| 风控 | 规则 | — (规则不可替换, 硬约束) |

择时层是 AI 升级的最高优先级——当前 IC=0.27 说明选股能力没问题, 亏损来自错误的市场暴露。

## 五、择时层 AI 升级方案 (v0.14)

### 5.1 问题定义

二分类: 未来 N 日 (N=5/10/20) 大盘上涨概率。

### 5.2 特征

| 类别 | 特征 |
|------|------|
| 价格 | 大盘指数 MA5/10/20/60 偏离度 |
| 宽度 | 上涨家数占比、新高新低比、行业上涨占比 |
| 资金 | 成交额变化率、北向资金流向 |
| 波动 | ATR、波动率锥、VIX 代理 |
| 因子 | AI 因子截面离散度 (std across stocks) |

### 5.3 模型

LightGBM 或简单 MLP。不需要深度学习——择时是低维分类问题。

### 5.4 训练

标签: `大盘未来 N 日收益 > 0` (涨/跌)
样本: 日频, 2020-2026, 约 1500 条
验证: 滚动窗口 (训练 500 天 → 预测 60 天)

## 七、风险与缓解

| 风险 | 缓解 |
|------|------|
| 择时规则在极端行情失效 | 风控层硬止损独立于择时 |
| 多因子组合 IC 低于单因子 | 动态权重: 近 60 日 IC 高的因子权重加大 |
| 行业过度集中 | 行业中性: 单行业权重 ≤ 20% |
| 小市值流动性风险 | 日成交额 < 2000万过滤 |
| 模型/规则切换混乱 | 因子回测结果对比, 选 IC 更稳定的配置 |
