# 日志系统架构规范 v0.15.0

**日期**: 2026-08-06

---

## 一、总则

系统日志分两层，各有独立目录和格式：

| 层级 | 目录 | 文件命名 | 格式 | 读写方式 |
|------|------|---------|------|---------|
| **公共日志** | `logs/system/` | `system_YYYY-MM-DD.log` | 纯文本，`[模块] 消息` | `InternalLogger` → `std::clog` / 文件重定向 |
| **策略日志** | `logs/策略名/` | `trade_YYYY-MM-DD.log` | 纯文本，结构化 | `TradeJournal` 类 |

## 三、策略日志 — 策略专属事件

### 3.1 输出位置

```
logs/策略名/trade_YYYY-MM-DD.log
```

由 `TradeJournal` 类管理，每个策略独立文件。

### 3.2 日志格式（纯文本，全中文）

```
YYYYMMDD 事件类型 参数...
```

### 3.3 事件类型清单

| 事件 | 格式 | 触发时机 | 路径 |
|------|------|---------|------|
| **冻结** | `YYYYMMDD 冻结 原因:规则闸门/择时空仓` | 策略EOD评估时市场闸门或择时禁止新开仓 | 实盘 |
| **拒绝** | `YYYYMMDD 拒绝 SYMBOL 规则:RULE_ID 模板:TEMPLATE_ID` | 买入信号被规则闸门拦截 | 回测 |
| **风控拒绝** | `YYYYMMDD 风控拒绝 SYMBOL 原因` | 订单被RiskEvaluator拦截 | 回测 |
| **买入** | `YYYYMMDD 买入 SYMBOL N股 PRICE` | 买入订单成交 | 回测 |
| **卖出** | `YYYYMMDD 卖出 SYMBOL N股 PRICE 盈亏:±PNL` | 卖出订单成交 | 回测 |
| **提交** | `YYYYMMDD 提交 买入/卖出 SYMBOL N股` | 订单提交到券商(实盘EOD) | 实盘 |
| **日终** | `YYYYMMDD 日终 持仓:N 净值:VALUE 现金:CASH` | 每日收盘后快照 | 实盘/回测 |

### 3.4 策略日志必须覆盖的闭环

```
信号生成 → 规则审核 → 风控检查 → 订单提交 → 成交确认 → 持仓更新 → 日终快照

  策略日志中每条链路上都有记录:
  买入: (提交 →) 买入成交 → 日终快照中有该持仓
  卖出: (提交 →) 卖出成交 + 盈亏 → 日终快照中无该持仓
  拒绝: 拒绝 + 规则名 → 不会出现后续成交
  冻结: 冻结 + 原因 → 当日无买入记录
```

### 3.5 当前缺口

| # | 缺口 | 影响 | 优先级 |
|---|------|------|--------|
| 1 | 实盘成交确认未记录 | GM回调 `on_order_status` 的成交/拒单未写入策略日志 | P0 |
| 2 | 行情数据域完全无日志(8个cpp 0条) | 数据断连/过期零诊断线索 | P1 |
| 3 | AccountEngine 无日志 | 账户资金变动无追踪 | P1 |
| 4 | EventBus 无订阅/分发日志 | 事件驱动架构运行状况不可见 | P1 |
| 5 | EngineImpl/Trigger/DataSource 69条日志无前缀 | 生产日志无法过滤 | P2 |
| 6 | TradeEngine 订单拒单无ERROR日志 | 生产拒单只能从返回值链追踪 | P2 |
| 7 | 回测域完全无日志(9个cpp 0条) | 回测组合过程无观测 | P2 |
| 8 | 无统一日志级别规范 | 同类事件在不同位置用了不同级别 | P2 |

## 四、TraceID 跨日志关联（P0 实施）

每条订单的完整生命周期（信号→风控→报单→成交）共用同一个 TraceID：

```
格式: YYYYMMDD_策略名_序号

示例:
  公共日志: 20260807 09:31:05.123 [TradeExec] [20260807_AIv2_0001] 订单提交 ...
  策略日志: 20260807 提交 买入 300767.SZ 1000股 [20260807_AIv2_0001]
  策略日志: 20260807 成交 买入 300767.SZ 1000股 15.32 [20260807_AIv2_0001]

排障时: grep 20260807_AIv2_0001 logs/ → 全链路视图
```

当前缺口：TraceID 尚未实现，需要在 `OrderRequest` 或 TradeJournal 层面生成。

## 六、日志级别规范

| 级别 | 用途 | 示例 |
|------|------|------|
| **DEBUG** | 开发调试，生产关闭 | 逐笔行情、因子值 |
| **INFO** | 正常业务流程 | 启动、同步完成、订单提交、日终 |
| **WARN** | 需关注但不影响运行 | 冻结、拒绝、连接断开、缓存缺失 |
| **ERROR** | 异常需要处理 | PG查询失败、解密失败、验签失败 |

生产环境建议级别: **INFO**

## 七、日志轮转与保留

| 类型 | 保留策略 |
|------|---------|
| 公共日志 | 保留 30 天，按月归档 |
| 策略日志 | 保留 90 天（覆盖一个完整评估周期） |
| 回测日志 | 每次回测独立文件，手动清理 |
