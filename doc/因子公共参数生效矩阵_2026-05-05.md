# 因子公共参数生效矩阵（2026-05-05）

## 口径确认

本文只统计以下 5 个“因子的公共参数”，不包含回测参数，也不包含 `skipRecent` 之类的因子专属参数：

1. 数据频率
2. 回溯窗口
3. 标准化方法
4. 滞后性开关
5. 中性化开关

当前统一参数 schema 定义在 [src/ui/bridge/src/FactorService.cpp](../src/ui/bridge/src/FactorService.cpp#L3331-L3335)。

## 状态定义

- 生效：进入因子公式或因子后处理，改变最终因子值。
- 仅预热：不进入因子公式，但会影响预热或前置校验。
- 仅记录：参数被解析或写入 metadata，但不改变最终因子值。
- 未接入：当前实现没有消费该公共参数。

## 责任归属

结论：这 5 个公共参数当前主要由因子实现层自己负责计算，不是由回测引擎统一负责复杂计算。

### 因子负责

- `BaseFactor` 直接把 `calculate` 和 `getDataRequirements` 作为因子实例职责，见 [src/domain/factor/include/BaseFactor.h](../src/domain/factor/include/BaseFactor.h#L136-L143)。
- `FactorInstanceManager` 按因子类型实例化具体因子类，见 [src/domain/factor/src/FactorInstanceManager.cpp](../src/domain/factor/src/FactorInstanceManager.cpp#L213-L233)。

### 引擎负责

- `FactorBacktestExecutor` 主要负责创建实例、调用 `calculateBatch`、收集 `CalculationResult` 并做 IC、分组收益、回测汇总，见 [src/domain/factor/src/FactorBacktestExecutor.cpp](../src/domain/factor/src/FactorBacktestExecutor.cpp#L2171-L2286) 和 [src/domain/factor/src/FactorBacktestExecutor.cpp](../src/domain/factor/src/FactorBacktestExecutor.cpp#L2798-L2808)。
- 回测引擎不会统一解释这 5 个公共参数。

### 唯一边界例外

- `lookbackPeriod` 当前会被控制器预热层读取，用于 warmup 历史长度准备，见 [src/ui/bridge/src/FactorBacktestController.cpp](../src/ui/bridge/src/FactorBacktestController.cpp#L842-L856)。
- 这属于前置数据准备，不属于因子公式主计算。

## 最终结论

在你重新确认的 5 个公共参数口径下，现在已经是“全部因子公共参数都参与了计算并影响结果”。

更准确地说：

- 当前已完整接入的是 Momentum、Value、Quality、Size、LowVol、Growth、Dividend、Technical、Liquidity、Macro、Industry、Sentiment、Custom。
- 当前不存在未完成的因子分支。
- `ConfigurableFactor` 子类型现在已经全部形成公共参数消费链，公共参数由各子类型 runtime 自己负责计算，回测引擎只负责调度和 warmup 准备。
