# 插件化组件注册架构实现总结

## 概述

本文档总结了在AStockQuantEngine中实现的插件化组件注册架构，该架构解决了动态参数配置和可扩展性问题，为因子创建界面提供了灵活、可扩展的参数组件管理方案。

## 架构设计

### 方案选择：方案2（插件化组件注册）+ 方案1（配置中心）

我们选择了**方案2（插件化组件注册）** 作为核心架构，结合**方案1（配置中心）** 的配置文件管理，实现了以下优势：

1. **插件化组件注册**：支持动态注册和扩展参数组件类型
2. **配置中心管理**：使用JSON配置文件管理因子参数定义
3. **向导式布局**：保留原有的四步向导式用户界面
4. **动态参数生成**：根据JSON Schema动态生成参数表单

## 实现文件

### 1. 核心集成文件

- **`CreationPagePluginIntegrated.qml`**：插件化架构集成版因子创建页面
  - 结合了向导式布局和插件化参数组件
  - 四步向导：选择类型 → 基本信息 → 参数配置 → 预览确认
  - 动态加载JSON Schema并生成参数表单

### 2. 插件化组件

- **`ParamComponents.qml`**：参数组件注册表
  - 统一管理所有参数组件类型
  - 提供组件注册和查找功能
  - 支持JSON Schema到参数配置的转换

- **`DynamicParamGenerator.qml`**：动态参数生成器
  - 根据配置动态生成参数表单
  - 支持参数验证和值变化通知
  - 自动布局和样式管理

- **基础参数组件**：
  - `SliderParam.qml`：滑块参数组件
  - `SelectParam.qml`：下拉选择参数组件
  - `InputParam.qml`：文本输入参数组件
  - `ToggleParam.qml`：开关参数组件

### 3. 配置文件

- **`config/views/factor_common.json`**：因子类型定义
- **`config/views/factor_common_params.json`**：参数配置定义

### 4. JavaScript工具

- **`FactorSchemaLoader.js`**：JSON Schema加载器
- **`FactorMetaLoader.js`**：元数据加载器
- **`FactorDefaultParams.js`**：默认参数配置

## 集成步骤

### 1. 更新FactorWorkbench

修改`FactorWorkbench.qml`，将原有的`CreationPageEnhanced`替换为`CreationPagePluginIntegrated`：

```qml
// 3. 创建因子页面 - 使用插件化架构集成版
CreationComponents.CreationPagePluginIntegrated {
    id: creationPage
    anchors.fill: parent
    anchors.topMargin: 40
    visible: root.currentMode === "create"
    selectedType: root.selectedType
    factorService: root.factorService
    onFactorCreated: function(factorData) {
        handleFactorCreated(factorData.displayName, factorData.majorCategory, 
                           factorData.description, factorData.parameters)
    }
    onTypeChanged: function(type) {
        root.selectedType = type
    }
    onBackClicked: switchMode("home")
}
```

## 使用示例

### 新增参数类型

1. **创建新组件**：创建新的参数组件，如`ColorPickerParam.qml`
2. **注册组件**：在`ParamComponents.qml`中注册新组件类型
3. **更新配置**：在JSON配置文件中添加新参数类型的定义
4. **使用组件**：新参数类型自动可用，无需修改界面代码

### 修改参数配置

1. **编辑配置文件**：修改`factor_common_params.json`
2. **重新加载**：应用程序自动加载新配置
3. **立即生效**：界面自动更新，无需重启
