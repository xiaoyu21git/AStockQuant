# 单因子测试方案（默认成本与指标口径）

## 1. 目标
在不调整手续费/滑点/风险参数的前提下，验证单因子在不同持有周期下的稳定性，并定位“短周期不过、长周期改善”的具体原因。

## 2. 固定参数（全部使用默认值）
- 数据源模式：`cache`（若缓存不可用再切 `database`）
- 基准：`000300.SH`
- 交易成本：`transactionCost = 0.001`（0.10%）
- 滑点：`slippageRate = 0.0`
- 无风险利率：`riskFreeRate = 0.0`
- 分组数：`10组`

说明：上述参数与当前 `FactorBacktestController::defaultBacktestRuntimeParams` 保持一致。

## 3. 单因子测试矩阵（只改持有/调仓节奏）
每个单因子依次跑以下 3 组：

- 组合 A：`forwardDays = 5`，`rebalanceDays = 5`
- 组合 B：`forwardDays = 10`，`rebalanceDays = 10`
- 组合 C：`forwardDays = 20`，`rebalanceDays = 20`

建议顺序：先价值（PB）、再规模（流通市值）、再流动性。

## 4. 因子参数建议（单因子基线）

### 4.1 价值因子（Value）
- `valuationType = pb`
- `usePercentile = true`
- `industryNeutral = false`

### 4.2 规模因子（Size）
- `sizeMetric = circulating_market_cap`
- `usePercentile = true`
- `industryNeutral = false`
- `standardization = zscore`（若回测页无显式选项，则保持系统默认）

### 4.3 流动性因子（Liquidity）
- 保持当前实例默认字段与窗口
- 仅在 A/B/C 三组中比较持有期差异

## 5. 指标与判定口径
按当前代码中的持久化合格阈值执行（默认）：

- `|IC| > 0.03`
- `|IR| > 0.50`
- `annualReturn > 0.15`
- `informationRatio > 1.0`
- `profitFactor > 1.5`
- `maxDrawdown <= 0.20`
- `turnoverRate <= 400`
- 分组条件：`严格单调` 或 `longShortReturn >= 0.03`

## 6. 结果记录模板（每个因子一行）
- 因子名
- A/B/C 三组的：IC、IR、年化、IRatio、ProfitFactor、MaxDD、Turnover、Top-Bottom
- 结论：
  - `短周期噪声型`（A 差、B/C 明显改善）
  - `稳定型`（A/B/C 差异不大）
  - `疑似过拟合型`（仅某一组异常好）

## 7. 决策规则
- 若 A 不合格、B 与 C 连续改善：采用中频节奏（10 或 20 天）
- 若 B 与 C 差异小：优先 10 天（更高资金周转）
- 若仅 C 明显好：优先 20 天并考虑和低波/质量做二因子组合
- 若 A/B/C 均不稳定：回到因子定义层，先排查字段质量、样本覆盖、行业暴露

## 8. 执行注意事项
- 每次仅改一个维度（本方案只改 `forwardDays/rebalanceDays`）
- 保持同一回测区间和同一股票池，避免样本切换引入偏差
- 跑完单因子再做组合，不要混在同一轮里判断
