# 0.9.x 稳定版必须完成清单

## 1. 版本目标

0.9.x 的定位是稳定测试版，不追求继续扩能力，而是把当前已经跑通的主链锁住，保证可用、可测、可回归。

这一版的核心原则是：

- 不再扩大主结构。
- 不再引入新的兼容兜底。
- 不再追求新增功能面。
- 只修阻断问题、回归问题和必要的小范围修补。

## 2. 0.9.x 必须完成的功能

### 2.1 数据管理主链稳定

必须完成：

- 数据源管理可正常打开和切换。
- 数据查询可正常返回结果。
- 数据预览可正常展示。
- 数据清洗可正常执行。

验收标准：

- 数据管理页不会因为基础操作报错或卡死。
- 关键查询和清洗入口可重复使用。
- 当前主链在回归时结果稳定。

### 2.2 因子工作台稳定

必须完成：

- 因子工作台可正常打开。
- 因子选择、查看、验证入口可用。
- 因子回测入口可正常触发。
- 常见因子在稳定版中保持可选性和可验证性。

验收标准：

- 打开因子工作台不会出现明显卡顿或异常。
- 因子选择和状态展示一致。
- 基础因子在稳定版中不会因界面或缓存问题失效。

### 2.3 策略回测稳定

必须完成：

- 策略回测能够完整执行。
- 回测结果可以正常返回并展示。
- 回测状态、进度、结果回写链路保持可用。

验收标准：

- 回测不出现链路断裂。
- 回测结果不丢失。
- 回测结束后页面状态可恢复。

### 2.4 清洗主流程稳定

必须完成：

- 清洗规则可正常执行。
- 清洗结果可正常保存和加载。
- 清洗过程中不出现重复报错或死循环。

验收标准：

- 清洗任务可重复执行。
- 清洗结果链路稳定。
- 清洗不会影响主链基本可用性。

## 3. 0.9.x 允许做的事情

- 修复阻断性缺陷。
- 修复回归问题。
- 修复界面卡顿、按钮失效、链接错误等基础问题。
- 做不改变语义的小范围性能修补。

## 4. 0.9.x 不应做的事情

- 不应新增大结构。
- 不应做主链重构。
- 不应强行补齐风险、交易、组合等扩展链路。
- 不应把推进版中的未完成逻辑直接合入。

## 5. 0.9.x 发布前检查

1. 数据管理主链是否稳定。
2. 因子工作台是否稳定。
3. 策略回测是否稳定。
4. 清洗流程是否稳定。
5. 关键回归是否通过。
6. 最近一次修复是否没有引入新的主链问题。

## 6. 0.9.x 完成标准

当以下条件满足时，0.9.x 可以认为完成：

- 主链功能可稳定跑通。
- 回归测试可稳定通过。
- 关键页面和关键服务无明显阻断问题。
- 当前版本可以作为后续推进版的测试基线。

## 7. 结论

0.9.x 不是“把所有功能做完”，而是“把当前能用的主链稳住”。

只要主链稳定、回归可控、没有明显阻断问题，就可以进入 0.10.x 的推进阶段。
