# 因子组合规律与策略分层边界

更新时间：2026-05-26

基于本轮关于因子组合、多频率策略边界、因子转策略、股票池合同和回测职责的全部讨论，核心要点收敛为两张表和一段总结。

## 一、因子组合的核心规律

这些是多个因子在信号层面合成时，必须遵循的技术铁律。

| 规律维度 | 具体要求 | 错误示例 |
| :--- | :--- | :--- |
| 候选池一致 | 参与合成的所有因子值，必须在完全相同的股票集合内计算和标准化。 | 将沪深300内算的价值因子，与中证500内算的动量因子，直接拼在一起排序。 |
| 信息截止时间一致 | 所有因子的输入数据，必须基于同一决策时点前已完整生成的信息，杜绝未来数据。 | 在10:00决策时，动量因子用09:59数据，但流动性因子用了10:00的盘口快照。 |
| 截面标准化一致 | 合成前，必须在同一个候选池截面上，对各因子做 Z-score 等标准化处理，使其具备横向可比性。 | 直接对原始值，如 0.01 的动量值和 10 亿的市值相加，导致量纲主导结果。 |
| 频率对齐一致 | 不要求原始数据同频，但组合时点上的因子值必须频率对齐。高频降频、低频升频或映射到同一决策频率。 | 把每 1 分钟更新的因子值，和每 5 分钟更新的因子值，在非重合时间点直接相加。 |

## 二、策略使用因子的边界与分工

这些是构建多因子、多频率策略时，因子角色的设计准则。

| 策略/因子类型 | 角色定位 | 使用边界 | 组合方式 |
| :--- | :--- | :--- | :--- |
| 纯单频策略 | 选股与择时合一 | 所有因子必须同频，或按上表规律对齐，并在同一池内合成一个复合因子进行排序。 | 因子层直接等权、IC 加权合成。 |
| 低频因子（月/季） | 战略定池：决定长期投资域和风格 | 不直接给出短期交易信号，作为风控总开关或资产池过滤器。 | 独立成层，为后续中高频提供白名单或仓位系数。 |
| 中频因子（日/周） | 战术精选与节奏控制：在低频池内二次选股，判断未来数日是否可操作 | 只在低频池内选股，不上浮到资产配置，不下沉到逐笔执行。 | 作为衔接层，输出高关注清单和市场状态信号。 |
| 高频因子（分钟/Tick） | 执行优化：在中频清单和可操作时段内，捕捉微观点位 | 绝不允许跨出中低频定好的池子选股，强制过滤池外信号。它负责何时买卖，不负责买卖什么。 | 被限定在白名单内触发条件单，或降频后参与因子合成。 |
| 短期策略（日内/几日） | 选股主力为中高频因子，低频仅作风控 | 不使用低频因子选股，但可用低频指标，如均线、排雷清单，控制总仓位或避开雷区。 | 中高频因子合成主信号，低频因子输出布尔值开关。 |

## 总结

这些规则共同指向一个核心逻辑：因子是特定域和特定频率上的相对排序工具，其值不能跨域、跨时、跨频直接比较。策略设计的本质，就是按照“长定范围、中断方向、短定时机”的漏斗原则，明确每个因子的决策边界，让它们在各自擅长的时空维度上发挥作用，并通过严格的信息对齐和分层过滤，将它们组织成一个不自相矛盾的决策体系。违反这些边界，回测就会因前视偏差或信息错配而虚高，导致实盘失效。
