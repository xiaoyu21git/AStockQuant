## 一、项目背景与目标

### 1.1 要解决的问题

当前量化策略的因子输入全部来自**结构化行情数据和财务报表**，完全缺失对外部非结构化信息（财经新闻、公司公告、社交媒体、行情异动）的感知能力。这意味着：

- 业绩预告大幅超预期的股票，策略无法提前反应
- 公司被立案调查的消息发布后，策略仍在按原权重买入
- 行业政策重大变化，风控参数一成不变

### 1.2 目标

在现有 EventBus + FactorSystem + RiskManager 基础设施之上，增加**金融事件感知能力**：

1. **感知**：从东方财富、巨潮资讯、雪球等信息源实时抓取金融文本
2. **理解**：通过 NLP 将非结构化文本转化为结构化金融事件（情感分、关联标的、事件类型、标签）
3. **决策辅助**：
   - 事件驱动因子：事件情感分影响策略的选股权重
   - 风控事件订阅：负面事件动态收紧风控参数

### 1.3 设计原则

1. **不重复造轮子**：复用现有 EventBus / FactorInstanceManager / RiskManager
2. **Python 做采集+NLP，C++ 做消费+决策**
3. **零侵入**：修改现有文件仅限于注册和集成，不改变现有模块内部逻辑
4. **单点故障不影响全局**：单条新闻 NLP 异常、单个信息源断连，不影响策略主流程

### 4.3 financial_lexicon.py (核心)

```python
"""
金融情感词典引擎
- 词典结构: {"预增": 0.55, "立案调查": -0.9, ...}
- 程度副词加权: "大幅预增" = 1.5 x 0.55 = 0.825
- 否定词翻转: "未能扭亏" = -0.6 (翻转)
- 输出: -1.0 ~ 1.0 金融情感分
"""

class FinancialLexicon:
    DEGREE_ADVERBS = {
        "大幅": 1.5, "显著": 1.3, "明显": 1.2, "小幅": 0.7,
        "略微": 0.5, "极大": 1.6, "严重": 1.5,
    }
    NEGATION_WORDS = {"不", "未", "无", "非", "没", "难以", "未能", "无法"}
    NEGATION_WINDOW = 4  # 否定词后 N 个词受影响

    def __init__(self, lexicon_path: str = None):
        with open(lexicon_path or "financial_sentiment_lexicon.json") as f:
            data = json.load(f)
        self._words: dict[str, float] = data["words"]
        self._phrases: dict[str, float] = data["phrases"]

    def phrase_score(self, text: str) -> float:
        return self._phrases.get(text, self._words.get(text, 0.0))

    def score_sequence(self, tokens: list[str]) -> tuple[float, list]:
        """
        分词序列 → 加权情感分
        """
        total = 0.0
        trace = []
        negated = False
        neg_window = 0
        degree_mult = 1.0

        for token in tokens:
            if token in self.DEGREE_ADVERBS:
                degree_mult = self.DEGREE_ADVERBS[token]
                continue
            if token in self.NEGATION_WORDS:
                negated = True
                neg_window = self.NEGATION_WINDOW
                degree_mult = 1.0
                continue
            if negated:
                neg_window -= 1
                if neg_window <= 0:
                    negated = False

            s = self.phrase_score(token)
            if s != 0.0:
                s = s * degree_mult
                if negated:
                    s = -s
                total += s
                trace.append((token, s))
            degree_mult = 1.0

        final = max(-1.0, min(1.0, total / max(1, len(tokens) * 0.3)))
        return final, trace


class SentimentAnalyzer:
    """HanLP 分词 + FinancialLexicon 情感计算"""

    def __init__(self, lexicon: FinancialLexicon):
        self._lexicon = lexicon
        self._tokenizer = None

    def _ensure_tokenizer(self):
        if self._tokenizer is None:
            import hanlp
            self._tokenizer = hanlp.load(hanlp.pretrained.tok.COARSE_ELECTRA_SMALL_ZH)

    def analyze(self, text: str) -> tuple[float, dict]:
        self._ensure_tokenizer()
        tokens = self._tokenizer(text)
        score, trace = self._lexicon.score_sequence(tokens)
        detail = {
            "tokens": tokens,
            "trace": [{"word": w, "score": s} for w, s in trace],
            "token_count": len(tokens),
            "matched_count": len(trace),
            "coverage": len(trace) / max(1, len(tokens)),
        }
        # 漏判日志: 文本含疑似情感但词典未命中 (用于持续扩充词典)
        if detail["coverage"] < 0.05 and len(text) > 20:
            logging.debug(f"[Lexicon] 低覆盖文本 (coverage={detail['coverage']:.2f}): "
                          f"{text[:100]}... | tokens={tokens[:20]}")
        return score, detail
```

```python
class EntityRecognizer:
    """从文本提取关联标的代码"""
    def __init__(self):
        self._ner = None
        self._stock_names: dict[str, str] = {}   # 公司简称/全称 → 代码
        self._stock_codes: set[str] = set()      # 所有有效代码

    # 简称匹配歧义黑名单: 避免"中国平安"匹配到"平安银行"
    AMBIGUOUS_SHORT_NAMES: set[str] = {"平安", "兴业", "中信", "招商"}

    def load_stock_registry(self, stocks: list[tuple[str, str, str]]):
        """加载标的注册表 [(代码, 简称, 全称), ...]"""
        for code, short_name, full_name in stocks:
            self._stock_names[short_name] = code
            self._stock_names[full_name] = code
            alias = full_name.replace("股份有限公司", "").replace("有限公司", "")
            if alias != short_name:
                self._stock_names[alias] = code
            self._stock_codes.add(code)
        # 清空歧义简称 (避免单字简称误匹配)
        for ambiguous in self.AMBIGUOUS_SHORT_NAMES:
            self._stock_names.pop(ambiguous, None)

    def extract(self, text: str) -> list[str]:
        """HanLP NER + 正则匹配 → 标的代码列表"""
        self._ensure_ner()
        symbols = []
        result = self._ner(text)
        for entity_text, entity_type in result:
            if entity_type == "ORGANIZATION":
                code = self._stock_names.get(entity_text)
                if code and code not in symbols:
                    symbols.append(code)
        # 补充: 6位代码正则
        import re
        for m in re.finditer(r'\b(\d{6})\b', text):
            code = m.group(1)
            if code in self._stock_codes and code not in symbols:
                symbols.append(code)
        return symbols


class EventClassifier:
    """关键词规则 → 事件类型"""
    TYPE_RULES = [
        (FinancialEventType.EARNINGS,    ["业绩预告","业绩快报","年报","季报","净利润","预增","预亏","扭亏"]),
        (FinancialEventType.POLICY,      ["证监会","银保监","央行","国务院","产业政策","监管政策"]),
        (FinancialEventType.MATERIAL,    ["重组","收购","增持","减持","回购","分红","股权激励","停牌","复牌"]),
        (FinancialEventType.QUOTE_ALERT, ["涨停","跌停","放量","异动","拉升","跳水","新高","新低"]),
        (FinancialEventType.SOCIAL,      ["股吧","雪球","热议","热搜"]),
    ]
    def classify(self, text: str, source: InfoSource) -> FinancialEventType:
        scores = {t: sum(1 for kw in kws if kw in text)
                  for t, kws in self.TYPE_RULES}
        best = max(scores, key=scores.get)
        return best if scores[best] > 0 else FinancialEventType.ALERT


class TagExtractor:
    """关键词规则 → 结构化标签"""
    TAG_PATTERNS = {
        "超预期":     ["超预期","好于预期","优于预期"],
        "低于预期":   ["低于预期","不及预期","不达预期"],
        "立案调查":   ["立案调查","被证监会调查"],
        "问询函":     ["问询函","关注函","监管函"],
        "ST警示":     ["ST","*ST","退市风险警示"],
        "高分红":     ["高分红","高送转","大比例分红"],
        "大额减持":   ["大额减持","清仓减持","减持计划"],
        "回购计划":   ["回购计划","股份回购","回购注销"],
    }
    def extract(self, text: str) -> dict[str, str]:
        return {tag: "true" for tag, patterns in self.TAG_PATTERNS.items()
                if any(pat in text for pat in patterns)}


class NLPPipeline:
    """一站式 NLP: 实体 + 情感 + 分类 + 标签"""
    def __init__(self, lexicon, entity_recognizer, classifier, tag_extractor):
        self._sentiment = SentimentAnalyzer(lexicon)
        self._entities = entity_recognizer
        self._classifier = classifier
        self._tags = tag_extractor

    def process(self, title: str, content: str, source: InfoSource) -> FinancialEvent:
        full_text = f"{title}。{content[:500]}"
        symbols = self._entities.extract(full_text)
        score, detail = self._sentiment.analyze(full_text)
        confidence = min(1.0, detail["matched_count"] / max(1, detail["token_count"]))
        event_type = self._classifier.classify(full_text, source)
        tags = self._tags.extract(full_text)

        return FinancialEvent(
            source=source.value, title=title, summary=content[:200],
            symbols=symbols, sentiment_score=score, event_type=event_type,
            confidence=confidence, tags=tags,
            timestamp=int(time.time() * 1000),
        )
```

        self._last_refill = time.monotonic()

    async def acquire(self) -> bool:
        now = time.monotonic()
        elapsed = now - self._last_refill
        self._tokens = min(self._max_calls,
                           self._tokens + int(elapsed / self._period * self._max_calls))
        self._last_refill = now
        if self._tokens > 0:
            self._tokens -= 1
            return True
        wait = self._period / self._max_calls
        logging.debug(f"[RateLimiter] 限流等待 {wait:.1f}s")
        await asyncio.sleep(wait)
        return True


class BaseAdapter(ABC):
    """信息源适配器基类"""

    # 默认: 每分钟最多 60 次调用
    DEFAULT_RATE_LIMIT = (60, 60.0)
    # 默认: 最多重试 3 次, 指数退避
    DEFAULT_RETRIES = 3
    DEFAULT_RETRY_BACKOFF = 1.0
    # 默认: 每批最多 200 条
    DEFAULT_BATCH_SIZE = 200

    def __init__(self, source: InfoSource, pipeline: NLPPipeline,
                 publisher: EventPublisher):
        self._source = source
        self._pipeline = pipeline
        self._publisher = publisher
        self._rate_limiter = RateLimiter(*self.DEFAULT_RATE_LIMIT)
        self._seen_fingerprints: set[str] = set()
        self._session: Optional[aiohttp.ClientSession] = None

    async def _ensure_session(self):
        if self._session is None:
            timeout = aiohttp.ClientTimeout(total=30)
            self._session = aiohttp.ClientSession(timeout=timeout)

    async def _fetch_with_retry(self, url: str, **kwargs) -> Optional[str]:
        """带重试和指数退避的 HTTP GET"""
        for attempt in range(self.DEFAULT_RETRIES):
            try:
                await self._rate_limiter.acquire()
                async with self._session.get(url, **kwargs) as resp:
                    if resp.status == 200:
                        return await resp.text()
                    elif resp.status == 429:  # Too Many Requests
                        wait = (2 ** attempt) * self.DEFAULT_RETRY_BACKOFF
                        logging.warning(f"[{self._source}] 429 限流, {wait}s 后重试")
                        await asyncio.sleep(wait)
                        continue
                    else:
                        logging.warning(f"[{self._source}] HTTP {resp.status}")
                        return None
            except (aiohttp.ClientError, asyncio.TimeoutError) as e:
                wait = (2 ** attempt) * self.DEFAULT_RETRY_BACKOFF
                logging.warning(f"[{self._source}] 网络异常 (attempt {attempt+1}): {e}")
                if attempt < self.DEFAULT_RETRIES - 1:
                    await asyncio.sleep(wait)
        return None

    def _fingerprint(self, title: str, content: str) -> str:
        """SHA256 内容指纹 (前16位), 用于去重"""
        return hashlib.sha256(f"{title}|{content[:200]}".encode()).hexdigest()[:16]

    def _is_duplicate(self, fp: str) -> bool:
        """内存去重检查 (超过 10 万条时自动清理旧指纹)"""
        if fp in self._seen_fingerprints:
            return True
        self._seen_fingerprints.add(fp)
        if len(self._seen_fingerprints) > 100000:
            # 保留最近 50000 条
            self._seen_fingerprints = set(
                list(self._seen_fingerprints)[-50000:])
        return False

    def _process_item(self, title: str, content: str) -> Optional[FinancialEvent]:
        """处理单条信息: 去重 → NLP → 返回 FinancialEvent"""
        fp = self._fingerprint(title, content)
        if self._is_duplicate(fp):
            return None
        try:
            event = self._pipeline.process(title, content, self._source)
            if not event.symbols:
                logging.debug(f"[{self._source}] 无关联标的: {title[:40]}")
                return None
            return event
        except Exception as e:
            logging.error(f"[{self._source}] NLP异常: {title[:40]} | {e}")
            return None

    @abstractmethod
    async def poll(self) -> List[FinancialEvent]:
        """拉取一批新闻并返回金融事件列表"""
        ...

### 4.7 publisher.py — 事件发布客户端（详细设计）

```python
"""
金融事件 → C++ EventBus 发布客户端
- 单条发布: 实时新闻即时推送
- 批量发布: 盘前/盘后批量新闻一次性推送 (每次 ≤200 条)
- 失败处理: 单条失败不影响同批次其他事件
"""

import logging
import time
from typing import List

from .event_types import FinancialEvent


class EventPublisher:
    BATCH_SIZE = 200           # 每批最多发布条数
    MAX_RETRIES = 2            # 发布失败重试次数
    RETRY_DELAY_MS = 500       # 重试间隔

    def __init__(self):
        self._bus = None
        self._published_count = 0
        self._failed_count = 0
        self._last_publish_time = 0.0

    def _ensure_bus(self):
        """延迟获取全局 EventBus (避免循环导入)"""
        if self._bus is not None:
            return self._bus
        try:
            from astock_engine.core.eventbus_bridge_cpp_python import get_engine_bus
            self._bus = get_engine_bus()
        except ImportError:
            from astock_engine.core.eventbus_unified import UnifiedEventBus
            self._bus = UnifiedEventBus.instance()
        return self._bus

    def publish_batch(self, events: List[FinancialEvent]) -> int:
        """
        批量发布金融事件到 C++ EventBus

        策略:
        - 每批 ≤200 条, 超出则分批
        - 单条失败不影响同批其他事件 (独立 try-catch)
        - 失败事件重试 2 次, 仍失败则丢弃 + 告警

        Returns:
            成功发布数
        """
        bus = self._ensure_bus()
        if bus is None:
            logging.warning("[EventPublisher] EventBus 不可用, 丢弃 %d 条事件", len(events))
            self._failed_count += len(events)
            return 0

        success = 0
        for i in range(0, len(events), self.BATCH_SIZE):
            batch = events[i:i + self.BATCH_SIZE]
            for event in batch:
                if self._publish_one(bus, event):
                    success += 1

        self._last_publish_time = time.monotonic()
        return success

    def _publish_one(self, bus, event: FinancialEvent) -> bool:
        """发布单条事件 (含重试)"""
        event_format = self._to_event_format(event)
        for attempt in range(self.MAX_RETRIES + 1):
            try:
                bus.publish(event_format, priority=1)
                self._published_count += 1
                return True
            except Exception as e:
                if attempt < self.MAX_RETRIES:
                    time.sleep(self.RETRY_DELAY_MS / 1000.0)
                else:
                    logging.error(
                        "[EventPublisher] 发布失败(已重试%d次): %s | %s",
                        self.MAX_RETRIES, event.title[:50], e)
                    self._failed_count += 1
        return False

    def publish_one(self, event: FinancialEvent) -> bool:
        """单条实时发布 (盘中突发新闻)"""
        bus = self._ensure_bus()
        return self._publish_one(bus, event) if bus else False

    def stats(self) -> dict:
        """发布统计"""
        return {
            "published": self._published_count,
            "failed": self._failed_count,
            "last_publish_time": self._last_publish_time,
        }

    @staticmethod
    def _to_event_format(event: FinancialEvent):
        """FinancialEvent → EventFormat (pybind11)"""
        try:
            from eventbus_native import EventFormat, EventPriority
            fmt = EventFormat()
            fmt.type = event.event_type.value
            fmt.priority = EventPriority.NORMAL
            payload = event.to_event_format_data()
            for key, value in payload["data"].items():
                fmt.data[key] = value
            for key, value in payload["metadata"].items():
                fmt.metadata[key] = value
            return fmt
        except ImportError:
            return {
                "type": event.event_type.value,
                "data": event.to_event_format_data()["data"],
                "metadata": event.to_event_format_data()["metadata"],
            }
```

CalculationResult EventDrivenFactor::calculate(const CalculationContext& ctx) {
    CalculationResult result;
    const auto nowMs = std::chrono::duration_cast<std::chrono::milliseconds>(
        std::chrono::system_clock::now().time_since_epoch()).count();
    const int64_t cutoff = nowMs - m_params.maxEventAgeHours * 3600000LL;

    // 读锁: 拷贝一份局部缓存, 减少持锁时间
    std::unordered_map<std::string, std::vector<EventRecord>> localCache;
    {
        std::shared_lock<std::shared_mutex> lock(m_cacheMutex);
        for (const auto& [sym, records] : m_eventCache) {
            auto& local = localCache[sym];
            for (const auto& r : records) {
                if (r.timestampMs >= cutoff)  // 惰性清理: 跳过过期事件
                    local.push_back(r);
            }
        }
    }
    // 锁已释放, 以下纯计算

    for (const auto& sym : ctx.symbols) {
        auto it = localCache.find(sym);
        double score = (it != localCache.end())
            ? computeSignalScore(sym, it->second) : 0.0;
        if (std::isfinite(score))
            result.values[sym] = score;
    }

    // 标准化
    if (m_params.standardization != StandardizationMethod::NONE) {
        applyCommonStandardization(result.values, m_params.standardization,
                                   m_params.neutralization, ctx);
    }
    return result;
}

## 七、错误处理与降级策略

| 层级 | 异常 | 处理 | 影响 |
|------|------|------|------|
| Python Adapter | 网络超时/API限流 | 日志 + 跳过本轮 + 下轮重试 | 该轮新闻丢失 (1分钟后补) |
| Python NLP | HanLP 模型加载失败 | 日志ERROR + 降级到纯词典模式 | 情感精度略降(~80%→~75%) |
| Python NLP | 单条文本分析异常 | 日志WARN + 跳过该条 | 该条新闻丢失 |
| Python NLP | 无关联标的 | 日志DEBUG + 跳过 (新闻不关联任何A股) | 正常过滤 |
| Python Publisher | EventBus 不可用 | 日志ERROR + 丢弃 + 告警 | 该轮事件全部丢失 |
| C++ onEvent | event 解析失败 | 日志WARN + 跳过 | 该事件不缓存 |
| C++ FactorEngine | EventDrivenFactor 计算异常 | try-catch + 返回空因子值 | 该次compute无事件因子贡献 |
| C++ RiskManager | setRiskConfig 无效值 | 值域 clamp 保护 | 配置不被异常值破坏 |

**全局原则**: 单条事件/单标的异常不影响其他事件和其他标的的处理。

```python
# astock_engine/events/health.py
class HealthChecker:
    """定期验证 Python→EventBus→C++ 链路畅通"""

    PING_INTERVAL = 30  # 秒
    PING_EVENT_TYPE = "system.health.ping"

    async def run(self):
        while True:
            try:
                event = FinancialEvent(
                    source="health_checker",
                    title="ping", summary="",
                    event_type=FinancialEventType.ALERT,
                    timestamp=int(time.time() * 1000))
                ok = self._publisher.publish_one(event)
                if not ok:
                    logging.error("[HealthCheck] EventBus 不可用")
                    # 触发告警 (接入现有告警系统)
            except Exception as e:
                logging.error(f"[HealthCheck] 异常: {e}")
            await asyncio.sleep(self.PING_INTERVAL)
```

## 十三、EventBus 投递语义

| 属性 | 值 | 影响 |
|------|-----|------|
| 投递顺序 | 单消费者内严格有序 (FIFO) | EventDrivenFactor 和 EventRiskSubscriber 各自独立有序 |
| 跨消费者顺序 | 不确定 | 因子缓存更新和风控参数调整可能小有时间差(<1ms) |
| 可靠性 | at-most-once (进程内, 无持久化) | 进程崩溃时未处理事件丢失 |
| 背压 | drop_oldest_on_full (可配置) | 队列满时丢弃最旧事件 |

**设计影响**: 因子和风控的跨消费者无顺序保证是**可接受的**。因子消费事件时进行的是缓存更新（累积性），风控消费事件时进行的是参数调整（即时生效）。两者互不依赖对方的中间状态。
