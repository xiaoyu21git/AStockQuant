# 策略参数总合同（基类通用 + 类型个性化）

## 1. 目的

本文用于最终确认两层参数合同：
1. 策略基类通用参数（来自 `StrategyCommonConfig`）。
2. 各策略类型个性化参数（来自各策略类声明对应的 `*StrategySpec`）。

本文不使用 JS 配置反推，只引用领域层 C++ 声明。

## 3. 基类通用参数（StrategyCommonConfig）

以下 6 项是策略基类 `IStrategy` 的通用参数主合同：

1. `allowShort: bool`
- 是否允许做空。

2. `maxPositions: int`
- 最大持仓数量上限。

3. `maxWeightPerStock: double`
- 单票最大权重（比例 0-1）。

4. `minWeightPerStock: double`
- 单票最小权重（比例 0-1）。

5. `weightScheme: WeightScheme`
- 权重方案。
- 枚举：`EQUAL`、`MARKET_CAP`、`SIGNAL_STRENGTH`、`RISK_PARITY`。

6. `rebalanceFrequency: RebalanceFrequency`
- 调仓频率。
- 枚举：`DAILY`、`WEEKLY`、`MONTHLY`、`QUARTERLY`、`YEARLY`。

## 4. 类型个性化参数（按策略类声明）

原则：每个策略类型的个性化参数，来自该策略类构造函数第三个参数对应的 `*StrategySpec` 结构。

### 4.1 DOUBLE_MOVING_AVERAGE

- 类：`DoubleMovingAverageStrategy`
- Spec：`DoubleMovingAverageStrategySpec`
- 参数：
1. `fastPeriod: int` 快速均线周期。
2. `slowPeriod: int` 慢速均线周期。
3. `priceField: TechnicalPriceType` 价格字段选择（如收盘价）。

### 4.2 TURTLE_BREAKOUT

- 类：`TurtleBreakoutStrategy`
- Spec：`TurtleBreakoutStrategySpec`
- 参数：
1. `channelPeriod: int` 通道周期。
2. `breakoutMultiplier: double` 突破倍数。
3. `atrPeriod: int` ATR 周期。

### 4.3 BOLLINGER_BAND_MEAN_REVERSION

- 类：`BollingerBandMeanReversionStrategy`
- Spec：`BollingerBandMeanReversionStrategySpec`
- 参数：
1. `period: int` 布林带窗口周期。
2. `standardDeviationMultiplier: double` 标准差倍数。
3. `entryThreshold: double` 入场阈值。
4. `exitThreshold: double` 离场阈值。

### 4.4 RSI_MEAN_REVERSION

- 类：`RsiMeanReversionStrategy`
- Spec：`RsiMeanReversionStrategySpec`
- 参数：
1. `period: int` RSI 周期。
2. `oversoldLevel: double` 超卖阈值。
3. `overboughtLevel: double` 超买阈值。

### 4.5 MULTI_FACTOR_SELECTION

- 类：`MultiFactorSelectionStrategy`
- Spec：`MultiFactorSelectionStrategySpec`
- 参数：
1. `factorWeights: vector<FactorWeight>` 因子及权重列表。
2. `topN: int` 选股数量。
3. `industryNeutral: bool` 是否行业中性。

### 4.6 EARNINGS_SURPRISE

- 类：`EarningsSurpriseStrategy`
- Spec：`EarningsSurpriseStrategySpec`
- 参数：
1. `surpriseThreshold: double` 超预期阈值。
2. `holdDays: int` 持有天数。
3. `eventSources: vector<EventSourceKind>` 事件来源集合。

### 4.7 STATISTICAL_PAIR_TRADING

- 类：`StatisticalPairTradingStrategy`
- Spec：`StatisticalPairTradingStrategySpec`
- 参数：
1. `tradingPair: TradingSymbolPair` 交易对。
2. `hedgeRatio: double` 对冲比率。
3. `lookback: int` 回看窗口。
4. `entryZScore: double` 入场 Z 分数阈值。
5. `exitZScore: double` 离场 Z 分数阈值。

### 4.8 RISK_PARITY_ALLOCATION

- 类：`RiskParityAllocationStrategy`
- Spec：`RiskParityAllocationStrategySpec`
- 参数：
1. `assets: vector<SymbolId>` 资产列表。
2. `volatilityLookback: int` 波动率回看窗口。
3. `targetVolatility: double` 目标波动率。

### 4.9 MACHINE_LEARNING_SELECTION

- 类：`MachineLearningSelectionStrategy`
- Spec：`MachineLearningSelectionStrategySpec`
- 参数：
1. `modelId: uint64_t` 模型标识。
2. `featureIds: vector<uint64_t>` 特征标识列表。
3. `topN: int` 选股数量。

### 4.10 ORDER_FLOW_IMBALANCE

- 类：`OrderFlowImbalanceStrategy`
- Spec：`OrderFlowImbalanceStrategySpec`
- 参数：
1. `depthLevels: int` 盘口深度层数。
2. `imbalanceThreshold: double` 失衡阈值。
3. `maxHoldSeconds: int` 最大持有秒数。

### 4.11 VOLATILITY_SPREAD

- 类：`VolatilitySpreadStrategy`
- Spec：`VolatilitySpreadStrategySpec`
- 参数：
1. `underlying: SymbolId` 标的。
2. `optionChainFilter: OptionChainFilterSpec` 期权链过滤条件：
- `minDaysToExpiry: int`
- `maxDaysToExpiry: int`
- `minMoneyness: double`
- `maxMoneyness: double`
3. `historicalVolatilityWindow: int` 历史波动率窗口。
4. `entrySpreadUpper: double` 价差上阈值。
5. `entrySpreadLower: double` 价差下阈值。
6. `deltaNeutral: bool` 是否 Delta 中性。

## 5. 不属于通用参数的内容

1. 风险参数细项：归规则服务，随 `RuleConfig + RuleId` 存储。
2. 策略个性化参数：只属于对应策略类型的 `*StrategySpec`。
3. 运行时状态：策略对象私有成员，不纳入参数合同。
4. 时间戳：按需扩展，不作为当前强制参数项。

## 6. 合同使用规则

1. 先传 `StrategyCommonConfig`，再按 `StrategyType` 传对应 `*StrategySpec`。
2. 不允许跨策略复用不属于该类型的个性化参数字段。
3. 不允许把风险规则细项回灌到基类通用参数。
4. 不允许用 UI 文本字段替代 typed 字段。
