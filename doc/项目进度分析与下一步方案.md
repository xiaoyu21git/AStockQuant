## 四、当前最紧急的任务：因子分组回测功能

### 4.1 因子回测 vs 策略回测：为什么需要因子回测？

#### 4.1.1 核心区别
- **策略回测**：测试特定的交易策略（如双均线策略、RSI策略）在历史数据上的表现
- **因子回测**：评估因子的预测能力，验证因子是否有效，为策略开发提供基础

#### 4.1.2 因子回测的目的
1. **验证因子有效性**：检验因子是否具有预测股票未来收益的能力
2. **评估因子稳定性**：观察因子在不同市场环境下的表现是否稳定
3. **计算因子绩效指标**：IC（信息系数）、IR（信息比率）、换手率等
4. **为策略开发提供依据**：基于有效的因子构建量化策略

#### 4.1.3 为什么不能直接策略回测？
1. **策略开发流程**：
   ```
   因子发现 → 因子验证（因子回测） → 策略构建 → 策略回测 → 实盘交易
   ```
   - 因子回测是策略开发的前置步骤
   - 没有经过验证的因子，构建的策略缺乏理论基础

2. **信息层次不同**：
   - **因子**：描述股票特征的指标（如PE、ROE、动量等）
   - **策略**：基于因子或其他信号的具体交易规则
   - 因子是策略的"原材料"，策略是"成品"

3. **评估目标不同**：
   - 因子回测：评估因子的预测能力和稳定性
   - 策略回测：评估交易策略的盈利能力和风险特征

#### 4.1.4 因子分组回测的核心价值
通过将股票按因子值分组（如十分位），观察：
1. **单调性**：高因子值组的收益是否显著高于低因子值组
2. **区分度**：不同分组间的收益差异是否明显
3. **稳定性**：分组收益排序在不同时间段是否稳定
4. **经济意义**：因子背后的经济学逻辑是否成立

### 4.2 功能需求分析
因子分组回测是量化交易系统的核心功能，需要实现：
1. **因子分组**: 按因子值将股票分为多组（如十分位）
2. **分组回测**: 对每个分组进行独立回测
3. **绩效对比**: 比较不同分组的绩效表现
4. **IC/IR分析**: 计算因子的信息系数和信息比率
5. **可视化展示**: 分组绩效图表和统计表格
6. **因子有效性检验**: 统计检验因子预测能力

```cpp
struct FactorGroup {
    int groupId;                    // 分组ID
    QString groupName;              // 分组名称
    double minFactorValue;          // 最小因子值
    double maxFactorValue;          // 最大因子值
    QList<QString> stockCodes;      // 该分组包含的股票代码
    BacktestResult backtestResult;  // 回测结果
};

struct FactorBacktestConfig {
    QString factorId;               // 因子ID
    QString factorName;             // 因子名称
    int numGroups;                  // 分组数量（如10表示十分位）
    QString startDate;              // 回测开始日期
    QString endDate;                // 回测结束日期
    double initialCapital;          // 初始资金
    QString strategyName;           // 使用的策略
    // 其他回测参数...
};

struct FactorBacktestResult {
    FactorBacktestConfig config;    // 配置信息
    QList<FactorGroup> groups;      // 分组结果
    double icValue;                 // 信息系数
    double irValue;                 // 信息比率
    // 其他统计指标...
};
```
