# 因子回测结果指标接口合同

## 1. 目标

本文固定因子回测结果在三层之间的唯一合同：

- 计算层：`factor::BacktestResult`
- 桥接层：`FactorBacktestResultContract`
- 展示层：QML 仅消费 `backtestResult`、`summaryStats`、`icirResult`、`groupResults`

禁止再出现以下情况：

- QML 使用未在 C++ 合同中定义的字段
- 同一指标在 Controller 层被替换成其他指标
- 同一指标在不同页面使用不同字段名
- 因 `0` 被当成假值而显示成 `N/A`

## 2. 核心类

结果合同类：`src/ui/bridge/src/FactorBacktestResultContract.h`

设计要求：

- 每个计算结果对应一个独立函数
- QML 使用的 map 只能由该类统一构造
- `FactorBacktestController` 不再手写分散字段映射

当前统一出口：

- `buildGroupResults(const factor::BacktestResult&)`
- `buildIcirResult(const factor::BacktestResult&)`
- `buildSummaryStats(const factor::BacktestResult&)`

## 3. QML / C++ 主接口

### 3.1 根结果对象 `backtestResult`

| 字段 | 类型 | 来源 | 说明 |
|---|---|---|---|
| `factorId` | string | `FactorBacktestController::buildResultMap` | 当前回测因子 ID |
| `taskId` | string | `result.resultId` | 回测任务 ID |
| `executionTime` | int | `result.executionTimeMs` | 执行耗时 ms |
| `success` | bool | `result.status == "SUCCESS"` | 是否完全成功 |
| `status` | string | `result.status` | `SUCCESS` / `PARTIAL` / `FAILED` / `CANCELLED` |
| `config` | map | `buildConfigMap` | 回测参数快照 |
| `groups` | list | `FactorBacktestResultContract::buildGroupResults` | 分组结果 |
| `icirResult` | map | `FactorBacktestResultContract::buildIcirResult` | IC/IR 结果 |
| `summary` | map | `FactorBacktestResultContract::buildSummaryStats` | 汇总结果 |
| `results` | list | `FactorBacktestController::buildAggregatedResultMap` | 统一结果列表；单因子固定为 1 条，多因子为 N 条 |
| `factorIds` | list | `FactorBacktestController::buildAggregatedResultMap` | 统一因子 ID 列表；单因子固定为 1 条，多因子为 N 条 |
| `factorCount` | int | `FactorBacktestController::buildAggregatedResultMap` | 统一结果数量；单因子为 1，多因子为 N |

约束：

- 单因子和多因子必须保持同构结果合同，禁止再用空 `results` / 空 `factorIds` 区分两条展示路径。
- 展示层是否展示切换器，只能根据 `results.length > 1` 判断，而不是根据单/多因子口径分支。

### 3.1.1 单因子历史条目 `singleFactorRunHistory[]`

来源：`FactorBacktestController::buildSingleFactorRunEntry`

历史条目合同与单次回测结果保持同构，允许补充展示字段，但禁止改变核心结果结构。

| 字段 | 类型 | 说明 |
|---|---|---|
| `factorId` | string | 当前因子 ID |
| `factorName` | string | 因子展示名；缺失时由控制器补 `fallbackFactorName` |
| `taskId` | string | 回测任务 ID |
| `executionTime` | int | 执行耗时 ms |
| `status` | string | 回测状态 |
| `config` | map | 回测配置快照 |
| `summary` | map | 保持嵌套，不允许扁平化 |
| `icirResult` | map | 保持嵌套，不允许扁平化 |
| `groups` | list | 保持嵌套，不允许扁平化 |

约束：

- 历史卡片必须从 `modelData.summary.*` 和 `modelData.icirResult.*` 读取指标。
- 禁止在 Controller 层追加 `annualReturn`、`informationRatio`、`icValue` 这类顶层兼容字段。
- 历史条目与主结果对象的指标字段名必须保持一致。

### 3.3 IC/IR 结果 `icirResult`

| 字段 | 类型 | 计算函数 | 含义 |
|---|---|---|---|
| `icValue` | double | `icValue` | IC 均值，固定等于 `result.icirResult.icMean` |
| `icStd` | double | `icStd` | IC 标准差 |
| `irValue` | double | `irValue` | 因子 IR |
| `icPositiveRate` | double | `icPositiveRate` | IC 正率 |
| `icSampleCount` | int | `icSampleCount` | IC 样本数 |

约束：

- `icValue` 只能表示 IC 均值，不允许再混入 IR 或其他替代值。
- 当前合同没有 `icTStat`，QML 禁止再展示该字段。

### 3.4 分组结果 `groupResults[]`

| 字段 | 类型 | 计算函数 | 含义 |
|---|---|---|---|
| `groupIndex` | int | `buildGroupResult` | 组序号，从 1 开始 |
| `stockCount` | int | `buildGroupResult` | 分组平均股票数 |
| `returnRate` | double | `buildGroupResult` | 分组收益 |
| `annualizedReturn` | double | `buildGroupResult` | 分组年化收益 |
| `minFactorValue` | double | `buildGroupResult` | 组内最小因子值 |
| `maxFactorValue` | double | `buildGroupResult` | 组内最大因子值 |

约束：

- QML 只允许读取 `returnRate`，不允许再读取不存在的 `return`。
- 当前合同没有分组级 `volatility` / `sharpeRatio` / `maxDrawdown`，QML 禁止展示这些伪字段。

## 5. `N/A` 规则

唯一规则：

- `N/A` 只能在没有因子上下文时显示。

具体定义：

- `FactorBacktestPage.qml`：`selectedFactorIds.length === 0`
- `BacktestPage.qml`：`selectedFactorId` 为空
- `BacktestResultView.qml`：`backtestResult.factorId` 或 `backtestResult.config.factorId` 为空

禁止规则：

- 不允许因为数值为 `0` 显示 `N/A`
- 不允许因为字段缺失但已有因子上下文显示 `N/A`
- 在已有因子上下文时，缺失数值统一按 `0` 格式化显示

## 6. 修改要求

后续新增或调整因子回测结果时，必须同时满足：

1. 先在 `FactorBacktestResultContract` 中新增函数。
2. 再把对应字段加入 `buildSummaryStats` / `buildIcirResult` / `buildGroupResults`。
3. 最后由 QML 按本文档字段名消费。

禁止直接在 `FactorBacktestController.cpp` 或 QML 页面中临时拼接新口径。
