# 策略基类字段与元数据结构定义

日期：2026-05-30

## 1. 目标

在策略基类中补齐以下能力：

1. 当前策略名字。
2. 当前策略描述。
3. 当前策略 UUID。
4. 当前策略元数据结构。
5. 当前策略因子列表与规则列表。

本合同统一采用因子 ID 列表、规则 ID 列表，不采用字符串规则名或因子名做运行时识别。

## 2. 基础类型约定

```cpp
#include "foundation/Utils/Uuid.h"

using StrategyUuid = foundation::utils::Uuid;
using FactorId = std::uint64_t;
using RuleId = std::uint64_t;
```

说明：

1. UUID 直接复用现有 `foundation::utils::Uuid`，不再新增自定义 UUID 基础类型。
2. 因子与规则统一用 ID 列表表达依赖关系。
3. 名称和描述允许字符串，仅作为展示与说明字段。

## 3. 策略元数据结构

```cpp
struct StrategyMetadata final {
	StrategyUuid uuid{foundation::utils::Uuid::null()};
	std::string name;
	std::string description;
	StrategyBehaviorKind behaviorKind{StrategyBehaviorKind::Custom};
	std::vector<FactorId> factorIds;
	std::vector<RuleId> ruleIds;
	bool enabled{true};
};
```

## 4. 策略服务层数据结构

```cpp
struct StrategyData final {
	std::string name;
	std::string description;
	StrategyBehaviorKind behaviorKind{StrategyBehaviorKind::Custom};
	std::vector<FactorId> factors;
	std::vector<RuleId> rules;
	bool enabled{true};

	// 服务层内部字段，不作为 QML 直接持久化合同
	StrategyId id{0};
	StrategyUuid uuid{foundation::utils::Uuid::null()};
};
```

## 5. 策略基类新增字段与接口

建议在策略基类增加只读访问，统一由构造或装配阶段注入：

```cpp
class IStrategy {
public:
	[[nodiscard]] const std::string& strategyName() const noexcept;
	[[nodiscard]] const std::string& strategyDescription() const noexcept;
	[[nodiscard]] StrategyUuid strategyUuid() const noexcept;
	[[nodiscard]] const StrategyMetadata& metadata() const noexcept;
	[[nodiscard]] const std::vector<FactorId>& factorIds() const noexcept;
	[[nodiscard]] const std::vector<RuleId>& ruleIds() const noexcept;

protected:
	StrategyMetadata metadata_{};
};
```

## 6. 字段语义

1. name：策略展示名称。
2. description：策略说明文本。
3. uuid：策略稳定唯一标识，用于跨会话定位。
4. behaviorKind：策略行为类型枚举。
5. factorIds：当前策略依赖的因子 ID 列表。
6. ruleIds：当前策略依赖的规则 ID 列表。
7. enabled：策略启停状态。
8. id：服务层数据库主键，不作为策略业务主标识。

## 7. 实施边界

1. 不引入旧字段兼容映射。
2. 不使用字符串名称替代因子 ID 或规则 ID。
3. QML 边界可展示 name 和 description，内部执行链路只认类型和 ID。
4. 缺失 UUID、因子 ID、规则 ID 时直接失败，不做兜底补写。

## 8. 建议落点

1. 策略基础类型定义：src/domain/strategies/include/StrategyDefinitionTypes.h
2. 策略基类：src/domain/strategies/include/IStrategy.h
3. 策略装配入口：策略构造或工厂层统一注入 StrategyMetadata
