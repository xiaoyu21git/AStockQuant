# 因子系统级参数验收矩阵（2026-05-06）

## 验收目标

本文专门跟踪 3 个系统级验收目标：

1. UI 上展示的通用参数必须真实参与因子计算。
2. UI 上展示的个性化参数必须真实参与结果计算。
3. 存在权重参数的因子，权重值必须真实进入计算并改变结果。

## 状态定义

- 通过：已有确定性回归，能证明参数变化会改变结果或计算路径。
- 进行中：已有部分证据，但还缺少关键差分回归，不能判定整项完成。
- 不适用：该因子在当前 UI schema 中没有权重参数。
