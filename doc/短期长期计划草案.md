## 二、短期计划 — 收口期 (v0.10.4 ~ v0.10.5)

**核心原则**: 不收口不向前，不让技术债进入长期阶段。

### v0.10.4 — 因子回测支持判断统一

| 维度 | 内容 |
|------|------|
| **时间** | 1~2 周 |
| **类型** | 修订版 — 内部重构为主，不变接口语义 |
| **前置** | 无 |

**任务清单**:

| # | 任务 | 涉及模块 | 工作量 |
|---|------|---------|--------|
| 1 | 梳理当前判断入口：FactorService / FactorViewModel / BacktestController 三处的 `支持判断` 逻辑差异 | FactorService, FactorViewModel, BacktestController | 小 |
| 2 | 统一到 runtime 解析结果，抽取 `FactorSupportJudge` 类作为唯一入口 | core/factor | 中 |
| 3 | 删除 bridge 层的兼容回退逻辑（`ifType == "xxx"` 字符串路由等） | bridge | 中 |
| 4 | 因子实例 → 字段需求 → 回测执行 真源统一到 `factor_instance.full_config` | core/factor | 中 |
| 5 | 预检失败给出明确原因（字段缺失/类型不匹配/数据不足），替代模糊报错 | bridge + UI | 小 |
| 6 | 回归：因子选择 → 预检 → 回测三节点逐一验证 | tests | 中 |

**验收**:
- 同一因子在 选择/预检/回测 三处判断结果一致
- 不再出现 "可选但不可跑" 或 "可跑但无字段"
- 编译 0 error + 因子模块回归通过

| 维度 | 内容 |
|------|------|
| **时间** | 1~2 周 |
| **类型** | 修订版 — 性能优化 + 稳定性加固 |
| **前置** | v0.10.4 |

**任务清单**:

| # | 任务 | 涉及模块 | 工作量 |
|---|------|---------|--------|
| 1 | 排查当前清洗链路中的重复字段解析（同一字段多处解析、不同路径同一逻辑） | DataCleaningEngine | 小 |
| 2 | 收口到统一解析路径，去重 | DataCleaningEngine | 中 |
| 3 | 识别性能热点：profile 清洗流程，找慢查询/大循环/无索引扫描 | DataCleaningEngine, DataFetchController | 中 |
| 4 | 针对热点做批量化/索引优化/缓存复用 | DataCleaningEngine, DataServiceCache | 中 |
| 5 | 清洗结果稳定性：保存/加载/统计可重复执行验证 | DataCleaningEngine + tests | 小 |

**验收**:
- 清洗在可接受时间内完成（不劣于当前基线）
- 关键规则执行结果可追踪
- 清洗结果不丢失主数据语义

## 三、长期计划 — 建设期 (v0.11.0 ~ v1.0.0)

**核心原则**: 每条新链路必须闭环，不产生新的兼容兜底。

### v0.11.0 — DynamicWorkspace 合入 + 交易执行链

| 维度 | 内容 |
|------|------|
| **时间** | 2~3 周 |
| **类型** | **次版本** — 新功能模块 |
| **前置** | v0.10.5（收口期完成） |

**任务清单**:

| # | 任务 | 涉及模块 | 工作量 |
|---|------|---------|--------|
| 1 | 恢复 DynamicWorkspace（15 文件）：`git stash pop stash@{0}` | 全局 | 小 |
| 2 | 手动集成 CMakeLists.txt + main.qml，编译通过 | 构建 | 中 |
| 3 | 掘金 SDK 交易接口对接（GmSessionEngine 从回测扩展到实盘） | SDK桥接 | 大 |
| 4 | 下单链路：TradePanel → OrderManager → GmSessionEngine → 券商 | 交易链 | 大 |
| 5 | 回报链路：券商 → GmSessionEngine → EventBus → OrderManager → UI | 交易链 | 大 |
| 6 | 成交/持仓刷新：PlaceOrder → 成交回报 → PositionAccountEngine 更新 → TradePanel | 交易链 | 中 |
| 7 | 撤单链路 | 交易链 | 小 |
| 8 | TradingPanel / TradingPage 去演示化：固定值替换为真实行情/持仓 | UI | 中 |

**验收**:
- 动态工作区可在运行时增删页面/组件
- 下单 → 回报 → 成交 → 持仓刷新全链路可跑
- 交易面板从固定值变为真实数据驱动

## 五、风险与依赖

| 风险 | 级别 | 缓解措施 |
|------|------|---------|
| 短期未收口就进入长期，技术债扩散 | **高** | 短期每版本独立验收，不合格不下班 |
| DynamicWorkspace 回恢复后冲突大 | 中 | 独立分支先试合，冲突多则手动重建 |
| 掘金 SDK 实盘接口稳定性 | 中 | v0.11.0 先用模拟盘验证 |
| 组合构建算法复杂度超过预期 | 中 | v0.11.2 可降级为先做均值方差，后续迭代 |
| 短期任务挤压长期时间 | 低 | v0.10.x 每个不超过 2 周 |
